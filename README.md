## 📖 معرفی

**MTProto Proxy Store** یک صفحه‌ی وب خودکار است که لیست پروکسی‌های **تلگرام** (MTProto) را از چندین کانال مختلف جمع‌آوری کرده و به‌صورت مرتب به‌روزرسانی می‌کند.  
همه‌ی پروکسی‌ها از نظر **اتصال** و **تأخیر (Latency)** بررسی می‌شوند تا بتوانید بهترین گزینه را انتخاب کنید.

👉 **آدرس صفحه:**  
[**https://miladfaryad11.github.io/MTProto/**](https://miladfaryad11.github.io/MTProto/)

## ✨ امکانات

- 🔄 **به‌روزرسانی خودکار** — لیست پروکسی‌ها هر ۱۵ دقیقه یک بار به‌طور خودکار به‌روز می‌شود.
- ✅ **تشخیص وضعیت** — هر پروکسی با برچسب **Online** (آنلاین) یا **Offline** (آفلاین) مشخص شده است.
- ⚡ **نمایش تأخیر** — زمان پاسخ‌دهی هر پروکسی به میلی‌ثانیه نمایش داده می‌شود.
- 🔍 **جستجوی سریع** — می‌توانید با وارد کردن IP یا پورت، پروکسی مورد نظر را پیدا کنید.
- 📋 **کپی لینک** — با یک کلیک لینک پروکسی را کپی کنید.
- 📱 **QR کد** — برای هر پروکسی می‌توانید QR کد بگیرید و با دوربین تلگرام اسکن کنید.
